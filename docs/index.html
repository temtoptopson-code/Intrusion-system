Network Intrusion Detection System (NIDS)

This website provides public information about an academic cloud-based Network Intrusion Detection System project.

NIDS is a prototype that analyses network-event metadata and applies configurable, rule-based indicators to help authorised users review suspicious activity.

Important: This is an academic prototype, not a certified commercial security product. Detection results are heuristic indicators and should be reviewed by a qualified administrator. Only monitor networks for which you have explicit authorisation.
